## Nimbus

**Descrição:** Primeiro projeto utilizando ESP e motor brushless.

**Conclusões:**

- Projeto inovador com o uso de motores brushless para seu funcionamento;
- Notou-se as limitações e vantagens do uso dessa tecnologia;
- Foi de suma importância para a formulação de seguidores futuros, como o Táquion;
- Capacidade de aceleração e frenagens controladas;
- Potência elevada;

Motor Brushless: Ao invés de usar escovas para o contato elétrico interno ele usa ímas para criar um campo magnético para rotacionar o rotor.
Vantagens: Maior precisão, controle, potência e durabilidade.
Desvantagens: Maior complexidade do sistema.
